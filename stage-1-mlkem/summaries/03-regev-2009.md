# On Lattices, Learning with Errors, Random Linear Codes, and Cryptography: Regev (J. ACM 2009)

[← back to Stage 1](../README.md) · [Paper](https://cims.nyu.edu/~regev/papers/qcrypto.pdf) · Read 2026-10-21 15:08 → 2026-10-22 17:03 (about 26 hours, one day and two hours)

**Problem.** Lattice problems are believed hard even for quantum computers, but only in the
**worst case**: some instances are hard. Cryptography needs the **average case**: a *random* key
must be hard to break. Earlier lattice cryptography bridged that gap only with very inefficient
schemes. The question: is there a simple problem whose random instances are as hard as the hardest
lattice instances?

**The problems, in one line each.**

| Problem | Task |
|---|---|
| Lattice | All integer combinations of a basis: a regular grid of points in *n* dimensions |
| **SVP** / GapSVP | Find the shortest non-zero lattice vector / decide, approximately, how short it is |
| **CVP** / BDD | Find the lattice point closest to a target / the same, when the target is promised to be close |
| SIVP | Find *n* short independent lattice vectors |
| **LWE** | Given *A* and *b = A·s + e* (mod *q*), with *e* small random noise, find *s* |
| LPN (random linear codes) | LWE with *q = 2*: decoding a random linear code |

Without *e*, LWE is a linear system solved by Gaussian elimination. The small noise makes it hard.

**Key idea: the reduction.** Assume a black box that solves LWE on random instances. Regev uses it to
solve worst-case lattice problems, in an iterative loop:

1. **LWE → BDD on the dual lattice** (classical). The LWE solver decodes points near the dual lattice.
2. **BDD → narrower Gaussian samples** (the one quantum step). A BDD solution turns, via a quantum
   Fourier transform, into samples of a narrower Gaussian distribution on the original lattice.
3. **Repeat.** Start from a wide Gaussian, which is easy to sample; each round narrows it. Narrow
   samples are short vectors, which solves SIVP and GapSVP.

The tools are what make it work: probability (Gaussian noise and how it "smooths" over a lattice),
duality (the dual lattice), Fourier analysis, and reductions chained step by step. Two smaller
reductions complete the picture: *search to decision* (telling LWE apart from random is as hard as
finding *s*) and *worst case to average case*.

**Result.**
- **Theorem:** solving LWE gives a quantum algorithm for worst-case GapSVP and SIVP (approximation
  factor *Õ(n/α)*). So **breaking LWE is at least as hard as the hardest lattice instances**.
- **A public-key encryption scheme** built on LWE, using only additions mod *q*:
  - *Secret key:* *s*. *Public key:* *m* LWE samples *(aᵢ, bᵢ = ⟨aᵢ, s⟩ + eᵢ)*.
  - *Encrypt a bit:* sum a random subset of the samples; add *⌊q/2⌋* to the second part if the bit is 1.
  - *Decrypt:* compute *b − ⟨a, s⟩*. Close to 0 means 0, close to *q/2* means 1.
  - The noise must stay small enough for decryption to be correct: parameters balance correctness
    against security.

**The takeaway.** Years of deep mathematics are packed into one theorem. After it, a designer no
longer works with lattices directly: they implement LWE (a matrix, a vector, small noise, mod *q*),
which is simple to code, and inherit security from worst-case lattice hardness.

**Limitations.**
- **The reduction is quantum:** an LWE solver yields a *quantum* lattice algorithm. Classical
  reductions came later (Peikert 2009; Brakerski et al. 2013).
- **Large keys:** the public key is a matrix of *Õ(n²)* entries, and each ciphertext carries a single
  bit. Ring-LWE and Module-LWE replace the matrix with polynomials, which leads to Kyber.
- **Only passively secure (CPA):** a ciphertext can be modified without detection. Kyber adds the
  Fujisaki-Okamoto transform (paper 5) for CCA security.
- **Encryption only:** signatures (ML-DSA, FIPS 204) are built on the same family of lattice
  problems, but with a different design that this paper does not cover.
- **Real parameters come from attacks,** not from the theorem: Kyber's parameters are set by the
  best known lattice-reduction attacks.

**For this thesis.** Kyber is Regev's scheme with polynomials in place of integers (Module-LWE),
plus compression and the FO transform. Two links forward: (1) the core operation, *A·s + e*, becomes
a product of polynomials, computed with the NTT: **Stage 2**; (2) the secret *s* and the decryption
decision "close to 0 or to *q/2*" are exactly what a side channel tries to observe: **Stage 3**.
